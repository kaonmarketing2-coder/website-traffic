처음 사용하신다면 설정 가이드를 참고하세요.

⚙️ 초기 설정 방법

  1. Google Cloud Console 접속 → 프로젝트 생성
  2. API 및 서비스 → Google Analytics Data API 활성화
  3. 사용자 인증 정보 → OAuth 2.0 클라이언트 ID 생성 (웹 애플리케이션)
  4. 승인된 자바스크립트 원본에 이 페이지 URL 추가
  5. config.js에 Client ID와 GA4 Property ID 4개 입력
  6. 각 GA4 속성에서 방금 만든 OAuth Client ID 계정에 뷰어 권한 부여
⚠️ 설정 필요: config.js에서 OAUTH_CLIENT_ID와 각 사이트의 propertyId를 실제 값으로 변경해 주세요.
